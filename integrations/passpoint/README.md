# PassPoint management integration

These files mirror the kiosk source under the SchoolDay workspace's `passpoint-android` and `passpoint-design-preview` directories. Build the kiosk there with `python passpoint-android/build.py --esper`; preserve the existing app signing key and pairing cookies.

The exported provider authorizes every call by exact caller package plus the permanent SchoolDay agent signing certificate SHA-256. It exposes only health metadata and a cooperative process restart. UI responsiveness comes from a WebView evaluation callback every 15 seconds; backend health uses the authenticated, read-only class-list request every 60 seconds after pairing. No student actions are generated by monitoring. A restart loses an unfinished on-screen interaction, but preserves app storage and enrollment.

Agent snapshot fields distinguish stale telemetry, stale backend probes, background activity, and unavailable integration. Historical exit reasons are Android numeric categories, not stack traces or page contents. Full-device unattended viewing is not implemented: the existing remote module is a stub, and Android MediaProjection requires local per-session consent.
